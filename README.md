# 📄 AI-Powered Document Orchestrator
Domain: Business Process Automation | Type: AI Application | Tools: Streamlit, Groq API (LLaMA 3.3 70B), n8n, Python

## 🎯 Objective
Build and deploy a fully functional AI-Powered Document Orchestrator that:

Extracts structured intelligence from any uploaded document using a live LLM
Displays results as structured JSON output
Triggers a conditional email automation workflow via n8n webhooks
Demonstrates expertise in Dynamic AI Extraction and Business Process Automation (BPA)


## 🧠 What It Does

Upload a document (PDF or TXT)
Ask a natural language question about the document
AI analyzes and extracts structured data as a JSON object (powered by LLaMA 3.3 70B via Groq)
Review the extracted output live in the app
Send an alert email with full analysis — triggered via n8n webhook automation


## 🏗️ Architecture
User Upload (PDF/TXT)
        ↓
  Text Extraction (pdfplumber)
        ↓
  Groq API (LLaMA 3.3 70B)
        ↓
  Structured JSON Output
        ↓
  n8n Webhook Trigger
        ↓
  Email Automation (SMTP via n8n)
        ↓
  Final Answer + Email Body returned to Streamlit UI

## 🖥️ App Flow (3 Steps)

- Step 1 — Upload Your Document

Accepts .pdf and .txt files
Extracts raw text using pdfplumber for PDFs, native decode for TXT
Shows a 1000-character preview of extracted content

- Step 2 — Ask a Question

Free-text question input about the document
On clicking Analyze Document, the Groq API processes the full text + question

- Step 3 — Send Alert Email

Enter recipient email
Click Send Alert Mail — triggers the n8n webhook
Returns 4 outputs back in the UI:

Structured JSON extraction
Final analytical answer
Generated email body
Email automation status (SENT / PENDING)

# ⚙️ Setup & Installation
Prerequisites

Python 3.9+
Groq API Key — Get it here
n8n instance (cloud or self-hosted) with a configured webhook + email workflow

Installation
bashgit clone https://github.com/yourusername/ai-document-orchestrator.git
cd ai-document-orchestrator
pip install -r requirements.txt
Configure Secrets
Create .streamlit/secrets.toml:
tomlGROQ_API_KEY = "your_groq_api_key_here"
N8N_WEBHOOK_URL = "your_n8n_webhook_url_here"
Run Locally
bashstreamlit run app.py


## 🔒 Security Note

API keys are stored in st.secrets and never hardcoded
.streamlit/secrets.toml is excluded from version control via .gitignore
n8n webhook URL is treated as a secret credential
